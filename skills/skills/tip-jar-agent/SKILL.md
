# Automated Tip Jar & Thank-You Skill

## What the Skill Enables
This skill allows an AI agent to run an automated feedback reward system. When a user sends positive feedback, bug reports, or project suggestions to the agent's Mermail inbox, the agent automatically checks its wallet, dispatches a small token tip (e.g., $1.00 USDC), and replies to the user with an email containing the transaction confirmation.
